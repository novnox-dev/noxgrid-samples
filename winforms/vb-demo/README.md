# NoxGrid Demo - Sales Orders (VB.NET WinForms)

A standalone sample that shows how to use NoxGrid in a business application.
Open `NoxGridDemo.sln` in Visual Studio 2019 or later (2022 and 2026 included) and press **F5**.

| | |
|---|---|
| Project | Classic VB.NET WinForms (`.vbproj`), .NET Framework 4.7.2, VB language 15.5 (Visual Studio 2019 level) |
| NoxGrid reference | NuGet package `Nox.Grid` (restored automatically on the first build) |
| Data | Made-up data generated by `SampleData.vb` (not real companies or transactions). The same data on every run |

## Run

1. Open `NoxGridDemo.sln` → **F5**. The first build downloads the `Nox.Grid` package from nuget.org.
2. Double-click `MainForm.vb` to see the workbook (4 sheets), grids and columns in the designer.
  - Click the sheet tabs at the bottom to switch sheets. Select a grid and use **Edit Columns...** on its smart tag (▸) to change columns.
  - If NoxGrid is not in the Toolbox: right-click the Toolbox → **Choose Items...** → `.NET Framework Components` → **Browse** → `%UserProfile%\.nuget\packages\nox.grid\<version>\lib\net472\Nox.Grid.WinForms.dll`.

## Sheets

| Sheet | What it shows |
|---|---|
| **Shipping Board** | A styled view: Modern color scheme (bold headers, horizontal lines only), status icon + text (image column with an ImageList: Done, Active, Waiting, Late), label column (read-only color), shipped % progress bar, merged cells for the same sales rep, multi-column sort (rep → shipped %), bold red text below 30% (conditional format), header filters |
| Sales Orders | Unbound (`Rows.Add(values...)`), 7 column types (text, combo, number, date, check box, button), **Amount = Qty × Unit Price formula** (`=D1*E1`), picking an item fills in its price, urgent rows colored, red due date for past-due orders and gray text for orders on hold (CellFormatting), required fields (customer, item), frozen columns |
| Shipments | DataTable binding (`DataPropertyName`), automatic merging of equal values (order no., customer), returned in red and in transit in blue, editing a shipped quantity recalculates the remaining quantity of that order |
| By Customer | **Formulas that read another sheet** (`=SUMIF('Sales Orders'!B:B,A2,'Sales Orders'!F:F)`, `COUNTIFS`), merged title row, total, share and average formulas, percent format. Updates as soon as Sales Orders changes |

Toolbar: Add Order · Delete Rows · **Undo / Redo** · **Subtotals** (by customer) · **Past Due** · Find customer (filter) · Clear Filter · **Open Excel (as a new sheet)** · **Save Excel (all sheets)** · Save CSV · **Preview** · Preview All · Color scheme.

## Things to try

- Change a quantity or unit price in Sales Orders → the Amount formula and the **By Customer** sheet update at once. **Ctrl+Z / Ctrl+Y**.
- **Add Order** → pick a customer and an item (the price is filled in). Leave the customer empty to see the required-field mark.
- **Subtotals** → quantity and amount subtotals per customer ([+]/[-] on the left, 1 2 3 next to the headers). Click again to remove them.
- **Past Due** → only open orders past their due date (a filter on two columns).
- The **[Shipments]** button on an order row → jumps to the Shipments sheet filtered to that order.
- Edit a shipped quantity in Shipments → the remaining quantity is recalculated.
- **Ctrl+F / Ctrl+H** on any sheet → Find and Replace.
- **Shift+click** headers on the Shipping Board → add sort columns (numbered 1, 2 in the headers). Memos are limited to 40 characters.
- Drag to select a range → **Ctrl+C** → paste into Excel (and the other way around).
- **Save Excel** → an `.xlsx` with all 4 sheets (formulas, colors, merges, filters and frozen panes included).
- **Open Excel** → import an `.xlsx` made in Excel (first sheet) or a CSV file as a new sheet.
- Double-click a sheet tab to rename it, right-click to insert or delete sheets, **+** to add a sheet, drag to reorder.
- In the designer, right-click the Shipping Board grid → **NoxGrid Designer...** → change the color scheme and columns with a live preview.
